Module 1 — The 12 Notes

Q1: What are the 12 notes of music? Put them in order starting from C.

Answer

C — C# — D — D# — E — F — F# — G — G# — A — A# — B

These 12 notes make up the chromatic scale. Memorizing this order is one of the most important things you'll do in this entire course.

Q2: What does the # (sharp) symbol mean?

Answer

Sharp means "one fret higher" — or one semitone higher in pitch.

When you see C#, it means the note one fret above C. On guitar: if C is fret 8, C# is fret 9.

Q3: How many notes are there between one C and the next C (counting the first C but not the second)?

Answer: 12 notes

C – C# – D – D# – E – F – F# – G – G# – A – A# – B = 12 notes. This 12-note span is called an octave.

Q4: On the low E string, E is the open string (fret 0). What fret is F on?

Answer: Fret 1

F is one semitone above E — that's exactly one fret. So: fret 0 = E, fret 1 = F.

Q5: What note is on fret 3 of the low E string?

Answer: G

Count up from E: E (0) → F (1) → F# (2) → G (3). Each fret is one step up the chromatic scale.

Q6: True or False — The same 12-note pattern appears on every string of the guitar.

Answer: True

This is one of the most important ideas in guitar theory. The chromatic sequence repeats on all 6 strings. The only difference is which note each string starts on (open string note).

Q7: C# and D♭ — are these the same note or different notes?

Answer: Same note

C# and D♭ are enharmonic equivalents — two different names for the same physical pitch. On guitar, they're the exact same fret.
