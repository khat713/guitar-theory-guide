How to Use These Lessons

  1. Read the lesson — Each takes 20-40 minutes. Read it all the way through.
  2. Look at the examples — We show real guitar examples for everything.
  3. Do the practice exercises — Most lessons have exercises built in. Try them before looking at answers.
  4. Take notes — Write down things that confuse you.
  5. Come back to the Reference tab — When you're confused, look things up there.
