# 🎸 Guitar Theory Bootcamp

A complete, beginner-friendly music theory guide for guitar players. Learn music theory in **less than one month** using simple examples, visual diagrams, and 50+ practice exercises.

## Overview

This is a free, open-source curriculum designed to teach music theory to someone who:
- Can already read guitar tabs
- Has zero music theory knowledge
- Wants to understand how music actually works
- Needs it explained like they're in elementary school (but for adults)

**What you'll learn:**
- Week 1: The 12 notes and the fretboard
- Week 2: Intervals and scales
- Week 3: Chords and harmony
- Week 4: Reading music and analyzing songs

## Features

✅ **7 Complete Lessons** — Each 20-40 minutes  
✅ **50+ Practice Exercises** — With instant answers  
✅ **Quick Reference Guide** — Look things up fast  
✅ **Real Guitar Examples** — Everything in tabs and fretboard notation  
✅ **Interactive** — Learn by doing, not just reading  
✅ **Free** — No paywalls, no ads  

## Getting Started

### Option 1: Use Online (Recommended)
1. Visit: `https://yourusername.github.io/guitar-theory-guide/`
2. Click "Start Learning" on the home page
3. Work through the lessons in order

### Option 2: Deploy Your Own

**Prerequisites:**
- GitHub account
- Git installed (or GitHub Desktop)

**Steps:**

1. **Fork or Clone This Repository**
   ```bash
   git clone https://github.com/yourusername/guitar-theory-guide.git
   cd guitar-theory-guide
   ```

2. **Push to GitHub**
   - If you forked: It's already on your account
   - If you cloned: Create a new repo on GitHub and push it

3. **Enable GitHub Pages**
   - Go to Settings → Pages
   - Set source to `main` branch (or whichever branch you use)
   - Set folder to `/ (root)`
   - Click Save
   - Your site will be live at: `https://yourusername.github.io/guitar-theory-guide/`

4. **That's it!** The site is live. Share the URL.

## Customization

### Change Colors
Edit `css/style.css` and modify the CSS variables:
```css
:root {
    --primary: #1e88e5;      /* Change to your brand color */
    --secondary: #43a047;
    --accent: #fb8c00;
    /* etc. */
}
```

### Add Your Own Lessons
1. Copy `pages/lesson-1.html`
2. Rename to `pages/lesson-8.html`
3. Edit the content
4. Add a link to it in `pages/lessons.html`
5. Push to GitHub

### Add More Exercises
Edit `pages/practice.html` and add new quiz items following the same format.

## FAQ

**Q: How long will this take?**  
A: 4 weeks if you do ~1 hour per week. Can be faster if you dedicate more time.

**Q: Do I need to read sheet music already?**  
A: No! We teach you as part of Module 7.

**Q: Can I print this?**  
A: Yes! Print individual lessons and practice sheets.

**Q: Can I modify this for my students/class?**  
A: Yes! Fork it and customize away. Just credit the original.

**Q: Is this only for guitar?**  
A: The concepts apply to all instruments! We just use guitar examples.
